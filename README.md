# 회식·접대 식당추천 포탈 (버전 2)

여의도 회식·접대 후보 식당 89곳을 대상으로, 목적·인원·예산·도보시간·룸·주차 조건에 맞는 식당을 추천하고 최대 3곳까지 비교하는 포탈입니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 포탈 본체. 식당 데이터·FAQ·자료실 목록이 이 파일 안에 들어 있습니다. |
| `files/` | 자료실에서 여는 PDF 가이드 4건과 링크 미리보기 이미지(`preview.png`) |
| `관리용(비공개)/` | 운영용 엑셀 2건(`DINING_PICK_FAQ_수정.xlsx`, `DINING_PICK_자료실_수정.xlsx`). **공개 저장소·웹에 올리지 않습니다.** |
| `files/preview.png` | 링크 공유 시 보이는 대표 이미지(1200×630). 공개 주소는 `index.html` 상단 og:url·og:image·canonical에 지정(`https://asran99-spec.github.io/dept-portal/`), 주소가 바뀌면 세 곳을 함께 수정 |
| `이전버전/` | 이름 변경 전 원본(`restaurant-portal_v2.html`) 사본 |

`index.html`과 `files/` 폴더는 항상 같은 위치에 두어야 자료실의 '다운로드' 버튼이 동작합니다. 두 개를 함께 옮기거나 공유하세요.

## 시작하기

1. `index.html`을 더블클릭해 웹 브라우저로 엽니다. 별도 설치나 서버는 필요 없습니다.
2. 상단 메뉴에서 이동합니다: 홈 · 맞춤식당추천 · 전체식당검색 · 식당비교 · FAQ · 자료실. 현재 보고 있는 영역의 메뉴가 강조됩니다. 화면 너비 860px 이하(모바일)에서는 메뉴가 햄버거(≡) 버튼으로 접히며, 버튼에 현재 영역 이름이 표시되고 항목을 누르면 자동으로 닫힙니다.
3. 상단 메뉴 오른쪽의 달/해 아이콘 버튼으로 다크모드와 라이트모드를 전환합니다. 선택은 브라우저(localStorage)에 저장되며, 저장된 선택이 없으면 기기의 시스템 설정(다크/라이트)을 따릅니다.
4. 아래로 스크롤하면 화면 오른쪽 아래에 '맨 위로' 버튼이 나타나며, 누르면 부드럽게 맨 위로 이동합니다.

## 사용 방법 (4단계)

1. **조건 입력** — '맞춤식당추천' 탭에서 모임 목적(회식·접대), 참석 인원, 1인 예산(만원), 음식 분류, 최대 도보시간, 룸, 주차를 선택합니다.
2. **추천 결과 확인** — '추천 보기'를 누르면 점수 상위 5곳이 표시됩니다. 카드의 '추천 이유'와 '확인 필요' 항목을 함께 읽습니다.
3. **후보 비교** — 카드의 '비교 담기'로 2~3곳(최대 3곳)을 담고 '식당비교' 탭에서 가격·도보·수용 인원·룸·주차·적합도를 나란히 봅니다.
4. **전화 확인·예약** — 카드의 전화번호와 지도 링크로 식당에 직접 확인합니다. 포탈에서 예약이 확정되지는 않습니다.

결과가 마음에 들지 않으면 조건을 완화해 다시 '추천 보기'를 누르거나 '전체식당검색' 탭에서 직접 찾습니다.

## 탭별 기능

- **맞춤식당추천**: 조건에 따른 점수 상위 5곳. 조건을 바꾸면 다른 식당이 나타날 수 있습니다.
- **전체식당검색**: 식당명·메뉴·키워드·주소 검색, 음식 분류·룸·주차 필터, 정렬(이름순·최소가격 낮은순·최소가격 높은순·도보시간 짧은순).
- **식당비교**: 식당을 골라 담아 최대 3곳을 비교. 최선 값은 강조 표시됩니다.
- **FAQ**: 포탈 이용 방법, 회식·접대 장소 선정, 식당 정보 및 예약, 데이터 및 운영, 추천 기준 5개 분류. 위쪽 검색창에 키워드를 입력하거나(공백으로 구분한 단어를 모두 포함하는 질문·답변만 표시, 일치 단어 강조) 카테고리 버튼을 누르면 해당 FAQ만 보입니다. 검색과 카테고리는 함께 적용됩니다.
- **자료실**: `files/` 폴더의 PDF 4건을 목록으로 표시합니다. 파일명·설명·용량을 보여 주고 '다운로드' 버튼을 누르면 새 창 없이 한글 파일명으로 바로 저장됩니다. 분류 필터와 '내용 보기'로 요약도 볼 수 있습니다.

## 룸·주차 조건 (무관 / 선호 / 필수)

| 선택 | 처리 |
|---|---|
| 무관 | 가점도 필터도 적용하지 않음 |
| 선호 | 보유·가능이 확인되면 +5점. 없거나 미확인이어도 제외하지 않음 |
| 필수 | 보유·가능이 확인된 식당만 추천(+5점). 없음·불가·미확인 식당은 제외 |

확인되지 않은 식당까지 보려면 '선호' 또는 '무관'을 선택하세요.

## 추천 점수

- 회식은 회식기본점수, 접대는 접대기본점수에서 시작합니다. 최종 점수는 0~100점이며 외부 리뷰 평점이 아닌 내부 참고용입니다.
- 가감점: 최대가격까지 예산 이내 +5 / 최소가격만 예산 이내(최대가격 초과) -3 / 도보 5분 이내 +5, 6~10분 +3 / 참석 인원 입력 시 수용 확인 +5 / 룸·주차 선호·필수이고 확인되면 각 +5.
- 미확인 정보에는 가점을 주지 않습니다. 동점은 기본점수, 식당명, 식당 ID 순으로 정렬합니다.

## 추천에서 제외되는 경우

- 휴업·폐업으로 확인된 식당
- 1인 예산보다 최소 예상가격이 높은 식당
- 참석 인원보다 확인된 최대 수용 인원이 적은 식당
- 룸·주차를 '필수'로 선택했는데 확인되지 않았거나 없는 식당

수용 인원·가격·도보시간이 미확인인 식당은 제외하지 않고 카드에 '확인 필요'로 표시합니다. 점수가 높은 미확인 식당이 상위에 나올 수 있으므로 예약 전 '확인 필요' 항목을 확인하세요.

## 유의사항

- 식당 정보는 공개자료 기준(기초 조사 2026-09-16, 일부 2026-11-16 추가 확인)이며 실시간 정보가 아닙니다. 영업 여부·가격·예약 가능 여부는 이용 전 식당에 재확인하세요. 운영 상태가 '운영 확인 필요'인 식당에는 '영업 재확인'이 표시됩니다.
- 등록 수용 인원은 전체 좌석 또는 특정 룸 기준일 수 있습니다. 한 공간 동시 착석 가능 여부는 별도로 확인하세요.
- 독립 룸(별도 구획 공간)과 단체석(여러 명이 앉는 좌석)은 다릅니다. 주차 가능과 무료 주차 지원도 다릅니다.
- 등록되지 않은 신규 식당은 추천·검색에 포함되지 않을 수 있습니다.
- 자료실 PDF는 자체 제작한 일반 실무 참고용입니다. 접대비 집행·승인 기준 등 회사 경비 규정은 별도로 확인하세요.

## 관리자 안내

- 식당 정보를 고치려면 원본 데이터(엑셀 또는 포탈 데이터)를 수정한 뒤 포탈에 다시 반영합니다. 변경할 때 확인일과 근거를 함께 갱신하는 것을 권장합니다.
- 자료실 목록은 `index.html`의 `DOCS`에서 만들어집니다. 파일을 추가·교체·이름 변경하면 해당 항목의 `"file"`(`files/…` 경로), `"saveAs"`(저장되는 한글 이름), `"size"`(바이트 단위 용량)를 함께 고쳐야 합니다. 용량은 자동으로 읽어 오지 않습니다.
- 운영용 엑셀은 `관리용(비공개)/`에서만 보관하고 공개 저장소에는 올리지 않습니다.
- 사이트 대표 주소만 등록된 식당(경로 없는 지도 URL)은 '지도' 링크를 표시하지 않습니다. 식당별 지도·예약 URL을 `RESTAURANTS`의 `map`에 넣으면 표시됩니다. 전화번호 칸에 숫자가 없는 값은 링크 없이 문구로만 표시됩니다.
- 다운로드는 `index.html`과 `files/` 폴더를 같은 위치에 두었을 때 동작합니다.
